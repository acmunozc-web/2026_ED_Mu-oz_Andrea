GUÍA DE PRÁCTICAS #04 - GRÁFICA DE ÁRBOLES

1. Instalar Python 3.
2. Abrir una terminal en esta carpeta.
3. Ejecutar:
   pip install -r requirements.txt
4. Ejecutar:
   python main.py

El programa lee arboles.txt, construye dos árboles, genera reportes,
permite consultar nodos, grafica ambos árboles y mide el tiempo de ejecución.
